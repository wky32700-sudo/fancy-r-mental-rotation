# Fancy R Mental Rotation

Updated GitHub Pages experiment with a matched plain/fancy SVG R.

## Design
- Head posture: upright vs 45-degree right tilt
- Complexity: plain vs fancy
- Orientation: 0, 60, 120, 180 degrees
- Version: normal vs mirrored
- 5 repetitions per cell
- 80 experimental trials per posture, 160 total
- 8 practice trials per posture

The fancy R uses the same core SVG skeleton as the plain R. Decorative line paths are added to the same stimulus group, and the entire group is mirrored on mirror trials.

## Publish
Upload `index.html`, `style.css`, `experiment.js`, and `README.md` to the repository root. In GitHub Settings > Pages, select Deploy from a branch, `main`, and `/ (root)`.

Before formal collection, pilot on the intended lab computer, replace consent wording with the approved text, and verify that the CSV contains 176 rows: 160 experimental plus 16 practice.
